Contrato activo

Ruta soportada

Frontend
   -> POST /chat
        -> FastAPI
             -> RAG retrieval
             -> provider / model
                  -> JSON estructurado

Referencia del contrato: docs/contracts/chat_runtime_refactor_contract.md.

Puertas FastAPI

GET /health

Estado basico del backend.

GET /api/models/chat

Catalogo de modelos seleccionables para el chat.

POST /chat

Chat principal con RAG y runtime de modelos.

GET /api/runs

Listado normalizado de runs guardados por /chat.

GET /api/runs/summary

Metricas agregadas calculadas en backend.

GET /api/runs/timeseries

Serie temporal lista para graficas.

GET /api/traces/chat

Compatibilidad interna de trazas de chat.

GET /docs

Swagger UI generado por FastAPI.

GET /openapi.json

Contrato OpenAPI en JSON.

Comandos operacionales

Backend

cd /home/jose-gonzalez-oliva/LOCALES
source .venv/bin/activate
export APP_ENV=local
export BACKEND_BASE_URL=<backend-api-url>
export OLLAMA_BASE_URL=<model-runtime-url>
export USE_REMOTE_RAG=false
export DOCUMENTS_DB_PATH=/home/jose-gonzalez-oliva/LOCALES/DB/chunks/documents.sqlite
uvicorn app.main:app --host <backend-host> --port <backend-port>

Frontend

python -m http.server 3000 --directory frontend

Smoke /health

curl <backend-api-url>/health

Smoke /chat

curl -X POST "<backend-api-url>/chat" -H "Content-Type: application/json" -d "{\"message\":\"Que es un transformer?\",\"provider\":\"ollama\",\"model\":\"granite4.1:8b\",\"use_rag\":true}"

Runs guardados

curl "<backend-api-url>/api/runs?limit=25"
